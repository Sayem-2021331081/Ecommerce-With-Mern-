This is a full-stack E-commerce web project created by Team North using MERN.

This project is a modern, scalable, and fully functional e-commerce web application designed to deliver a smooth shopping experience. It includes product browsing, secure payment integration, an advanced admin dashboard, and all essential user functionalities.

***Tech Stack (MERN)
1. MongoDB – Database
2. Express.js – Backend Framework
3. React.js – Frontend
4. Node.js – Server Runtime

⭐ Key Features
***Authentication
1. User Sign Up & Login
2. Secure session handling

***User Dashboard
1. Editable profile
2. Order history
3. Saved cart items

***Shopping Features
1. Add to Cart
2. Real-time cart updates
3. Product details page

***Payment Integration
1. Secure checkout
2. Online payment support

***Admin Panel
1. Product management (Add/Edit/Delete)
2. Order management
3. User management
